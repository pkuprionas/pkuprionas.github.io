# Paul Kuprionas - Professional Portfolio Website

A modern, responsive portfolio website for Paul Kuprionas, showcasing Salesforce expertise and professional credentials.

## Features

- **Modern Design**: Clean, contemporary design with smooth animations and transitions
- **Fully Responsive**: Optimized for desktop, tablet, and mobile devices
- **Performance Optimized**: Fast loading with efficient CSS and vanilla JavaScript
- **Accessibility**: Semantic HTML and ARIA-compliant navigation
- **SEO Friendly**: Proper meta tags and semantic structure

## Sections

1. **Hero**: Eye-catching introduction with call-to-action buttons
2. **About**: Professional overview and key highlights
3. **Expertise**: Six core competency areas with detailed descriptions
4. **Certifications**: Links to Salesforce Trailblazer profile and certification credentials
5. **Contact**: Easy-to-access contact information

## Technologies Used

- HTML5
- CSS3 (with CSS Grid and Flexbox)
- Vanilla JavaScript
- Google Fonts (Inter)

## Local Development

Simply open `index.html` in your web browser to view the site locally.

For a better development experience with live reload:

```bash
# Using Python
python -m http.server 8000

# Using Node.js
npx serve

# Using PHP
php -S localhost:8000
```

Then visit `http://localhost:8000` in your browser.

## Deployment

This is a static website that can be deployed to any web hosting service:

- **GitHub Pages**: Free hosting for static sites

## Customization

### Colors
Edit the CSS variables in `styles.css`:
```css
:root {
    --primary-color: #00A1E0;
    --secondary-color: #032D60;
    --accent-color: #FFB500;
    /* ... */
}
```

### Content
Update the content directly in `index.html`

### Styling
Modify `styles.css` for layout and design changes

## Performance

- No external dependencies (except Google Fonts)
- Optimized animations with CSS transforms
- Intersection Observer for efficient scroll animations
- Minimal JavaScript for better performance
